# 如何发布我的文章

> 这篇页面本身是一份**草稿示例**——它展示了文章怎么写、有哪些开关。你可以保留它反复对照，也可以在我身上练手：修改后把 `draft: false`，再运行 `sh publish.sh` 就能正式上线。

## 一、新建一篇文章

```bash
hugo new post/文章名.md
```

会生成带注释的模板文件，用编辑器打开填写。

## 二、必改的两个开关

| 字段 | 说明 |
|---|---|
| `draft: true` | ★ 草稿状态。**改成 `false` 才会发布** |
| `title` | 文章标题，会显示在首页卡片、浏览器标签、分享链接里 |

## 三、分类 / 标签 / 系列（都是自动的）

在文章顶部 `front matter` 里填词即可，**不需要任何预建操作**：

```yaml
categories:
  - 建站          # 新词发布后自动出现在 /categories/ 页

tags:
  - Hugo          # 同理，出现在 /tags/ 页

series:
  - 从零搭建个人博客   # 同一系列的多篇文章，会聚合在 /series/ 页
```

**记住：分类/标签/系列页面是"长"出来的——文章写了才有，删完就没。**

## 四、摘要和"阅读全文"

正文中放一行标记，它**之前**的内容会作为首页摘要展示，后面的内容要点进文章才看到：

```markdown
这是会显示在首页上的开头内容……

<!--more-->          ← 这一行就是"摘要分割线"

这是全文内容，只在文章页看到。
```

`description: "一句话"` 用于搜索引擎和社交分享卡片，推荐填。

## 五、图片

把图片放进项目根目录的 `static/imgs/` 文件夹，正文里这样引用：

```markdown
![图片说明](/imgs/图片名.png)
```

## 六、本地预览（先看效果再发布）

```bash
hugo server -D
```

浏览器打开 <http://localhost:1313>，`-D` 才会显示草稿。改一个字保存，页面自动刷新。

## 七、正式发布（一条命令搞定）

```bash
sh publish.sh "发布我的第一篇文章"
```

这条命令自动完成三件事：**① Hugo 构建网页 → ② 推送到线上仓库（1~2 分钟后生效）→ ③ 自动备份源码到 GitHub**。发布后想确认？**Ctrl+F5 强刷**页面即可。
