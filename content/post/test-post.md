## 概要

这篇文章是用来**测试**的：它按"标题 + 概要 + 正文"的规范结构编写——本文开头的这段"概要"会在首页以摘要形式展示，配合"阅读全文"按钮；点击进入后就是完整正文。写完之后我把它正式发布了，现在你可以在首页看到它变成一张卡片，验证整套发布流程是否顺畅。

<!--more-->

## 一、这篇文章的结构

每篇文章建议按这个骨架写：

1. **标题**：文件顶部的 `title` 字段，是文章的"门面"
2. **概要**：正文开头的一段话，总结这篇文章讲了什么（`<!--more-->` 之前）
3. **正文**：`<!--more-->` 之后，文章的完整内容

首页只会展示"标题 + 概要 + 阅读全文按钮"，正文要点进来才能看到。

## 二、验证点清单

你可以依次检查这些地方是否正常：

- **首页**：看到本文卡片——标题、日期分类、概要段落、"阅读全文 »"按钮
- **文章页**：点进来看全文，右侧/侧栏有文章目录，文末有标签、上一篇/下一篇
- **分类页**：菜单"分类"→"建站"分类里躺着本文
- **标签页**：菜单"标签"→"Hugo"和"测试"
- **归档页**：菜单"归档"→ 本文出现在列表里

## 三、常见排版速查

```bash
# 代码块：带语法高亮和复制按钮
hugo server -D
```

- 列表项、**加粗**、*斜体*、`行内代码`
- > 引用块

## 四、如果你要删除这篇文章

把文件顶部 `draft: false` 改回 `draft: true`（变回草稿），或直接删除本文件，然后：

```bash
sh publish.sh "删除测试文章"
```

这就是博客的完整玩法——测试完就可以开始写自己的文章了。
